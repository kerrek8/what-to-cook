# WhatCook («Что приготовить?»)

Mobile-First PWA-приложение для рационального использования продуктов, учета содержимого холодильника и подбора рецептов с автоматическим формированием списка покупок.

Текущая версия приложения: **v0.5.5**

---

## 🛠 Стек технологий

* **Backend**: Go 1.22+, Gin REST API, PostgreSQL 16+, SQLC, pgx, golang-migrate, JWT (Access + HttpOnly Refresh).
* **AI & Медиа**: Sber GigaChat API (интеллектуальная нормализация ингредиентов, расчет времени/сложности, гастрономические промпты), нейросеть FLUX.1 (генерация ресторанных фуд-фото), локальное медиа-хранилище `backend/uploads/recipes/` с автоматическим билинейным ресайзом 512x512 и JPEG-сжатием.
* **Frontend**: Vue 3 (Composition API, `<script setup>`, TypeScript), Vite, Vant UI (мобильные компоненты), Pinia, Dexie.js (IndexedDB), `vite-plugin-pwa` (Workbox).
* **Инфраструктура**: Docker & Docker Compose, Nginx.

---

## 🚀 Быстрый запуск (Docker Compose)

Рекомендуемый способ запуска всего стека (PostgreSQL, миграции, Backend, Frontend):

```bash
# 1. Создать файл окружения
cp .env.example .env

# 2. Собрать и запустить все сервисы в фоне
docker compose up --build -d
```

### Доступные сервисы:
* **Frontend (PWA)**: [http://localhost:3000](http://localhost:3000)
* **Backend API**: [http://localhost:8080](http://localhost:8080)
  * Проверка работоспособности: `GET http://localhost:8080/health`
  * Документация Swagger UI: [http://localhost:8080/swagger/index.html](http://localhost:8080/swagger/index.html)
  * Раздача медиафайлов: `http://localhost:8080/uploads/recipes/`
* **PostgreSQL**: `localhost:5432`

Остановить контейнеры:
```bash
docker compose down
```

## 💻 Локальная разработка

### 1. База данных и миграции
Быстрый запуск только PostgreSQL и накат миграций через Docker:
```bash
docker compose up -d postgres migrate
```

### 2. Backend (Golang)
Требуется: Go 1.22+
```bash
cd backend

# Запуск сервера
go run ./cmd/server

# Запуск тестов и линтера
go test ./...
go vet ./...
```
*(При установленном [Task](https://taskfile.dev): `task run`, `task test`, `task lint`)*

### 3. Frontend (Vue 3 / PWA)
Требуется: Node.js 20+, pnpm 9+
```bash
cd frontend

# Установка зависимостей
pnpm install

# Запуск dev-сервера (http://localhost:5173)
pnpm dev

# Проверка типов и тесты
pnpm type-check
pnpm test
```

## ⚙️ Переменные окружения (`.env`)

Ключевые параметры (подробнее в [`.env.example`](.env.example)):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `POSTGRES_DB` / `USER` / `PASSWORD` | `whatcook` / `whatcook_password` | Учетные данные PostgreSQL |
| `POSTGRES_PORT` | `5432` | Порт PostgreSQL на хосте |
| `BACKEND_PORT` | `8080` | Порт REST API сервера |
| `FRONTEND_PORT` | `3000` | Внешний порт фронтенда в Docker |
| `JWT_SECRET` | `super_secret_jwt_key...` | Секретный ключ подписи JWT |
| `VITE_API_URL` | `http://localhost:8080` | Адрес API для фронтенда |
| `GIGACHAT_AUTH_KEY` | *(опционально)* | Base64-ключ авторизации Sber GigaChat API |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` | Скоуп доступа GigaChat (`GIGACHAT_API_PERS` / `GIGACHAT_API_CORP`) |
| `GIGACHAT_MODEL` | `GigaChat` | Модель GigaChat |
| `GIGACHAT_VERIFY_SSL` | `false` | Проверка SSL-сертификатов Минцифры для GigaChat |

## 📌 Возможности и функционал (v0.5.5)

Все запланированные этапы MVP дорожной карты полностью завершены и расширены:

* **Умный подбор рецептов («Что приготовить»)**:
  * Алгоритм сопоставления на основе содержимого холодильника с ранжированием по проценту совпадения.
  * Учет продуктов-аллергенов (1 бесплатный продукт-исключение на пользователя) и персональной базовой корзины (соль, масло, вода и др.).
  * Фильтр «🔥 Спасает продукты» для приоритетного использования ингредиентов с истекающим сроком годности.
  * Интерактивный экран рецепта с таймером готовки и кнопками точной регулировки (`-5м`, `-1м`, `+1м`, `+5м`).
* **Каталог рецептов и нейросетевой пайплайн**:
  * Стартовый сид миграции из 50 аутентичных блюд русской кухни с качественными ресторанными фуд-фотографиями FLUX.1.
  * Нормализация времени, сложности и названий ингредиентов через Sber GigaChat.
  * Фоновый воркер `RecipeWorker` для безопасного инжеста порциями из русскоязычного датасета `russian-recipes-parser`.
* **Холодильник (Инвентарь)**:
  * Быстрый учет продуктов: как по точному весу (`amount` + `unit`), так и по качественной оценке («много», «средне», «мало»).
  * Цветовая индикация свежести (зеленый / желтый / красный) и свайп-удаление карточек.
  * Серийное добавление («Добавить еще», «Добавить и закрыть»).
* **Список покупок**:
  * Добавление недостающих ингредиентов прямо из рецепта в один клик.
  * Автоматическая группировка по отделам супермаркета (овощи, молочка, мясо, бакалея).
  * Интерактивный перенос купленных товаров в холодильник с настройкой количества и срока годности.
* **PWA & Офлайн-устойчивость**:
  * Возможность установки на экран смартфона (`standalone`).
  * Service Worker (Workbox) для кэширования статики и IndexedDB (Dexie.js) для работы без сети.
  * Web Push уведомления о приближающемся окончании сроков годности.

Детальный отчет по всем этапам и задачам доступен в [`docs/roadmap.md`](docs/roadmap.md).
