# Перевод в WhatCook

Для перевода используется Go-библиотека `github.com/bregydoc/gtranslate` на backend. Браузер отправляет тексты на `POST /api/v1/translations`; backend обращается к Google Translate и возвращает результат. LibreTranslate в Compose больше не используется.

Перевод работает между английским и русским языками. Названия и категории холодильника, список покупок и видимые названия рецептов переводятся в фоне. Открытая карточка рецепта также запрашивает перевод описания, ингредиентов и шагов. Переводы кэшируются в localStorage браузера, а оригинальный текст остаётся виден, если внешний сервис недоступен.

Русский поисковый запрос переводится на английский перед поиском в локальном каталоге и TheMealDB. Исходные данные рецептов в базе не перезаписываются переводом.

Библиотека использует неофициальный endpoint Google Translate без ключа. Доступность и ограничения запросов контролирует Google; это не гарантированный публичный API. Backend ограничивает пакет десятью строками и кэширует повторные переводы в памяти процесса.

Для локальной проверки endpoint после запуска приложения:

```sh
curl -X POST http://localhost:8080/api/v1/translations \
  -H 'Content-Type: application/json' \
  -d '{"texts":["Hello world"],"source":"en","target":"ru"}'
```
