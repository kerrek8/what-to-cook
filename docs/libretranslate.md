# LibreTranslate для WhatCook

WhatCook использует LibreTranslate только для отображения и поиска. Исходные названия и категории в PostgreSQL не изменяются. Переводы хранятся в кэше браузера, а приложение продолжает показывать исходный текст, если переводчик недоступен.

## Локальный запуск через Docker Compose

Нужен установленный Docker Desktop. В корне репозитория запустите:

```powershell
docker compose up -d --build
```

LibreTranslate будет доступен приложению по адресу `http://localhost:5000`. Откройте WhatCook по адресу `http://localhost:3000`. При первом старте LibreTranslate скачивает языковые модели; первый запуск и первые переводы могут занять время. Модели сохраняются в Docker volume `libretranslate_data`.

Если фронтенд запускается отдельно через Vite, скопируйте `frontend/.env.example` в `frontend/.env.local`, оставьте `VITE_LIBRETRANSLATE_URL=http://localhost:5000` и перезапустите `pnpm dev`.

## Развёртывание LibreTranslate отдельно на Render

Создайте отдельный **Web Service** на Render из публичного Docker-образа `libretranslate/libretranslate:latest`. У сервиса должны быть те же регион и аккаунт, что у WhatCook. LibreTranslate нужно опубликовать по HTTPS, потому что браузер обращается к нему напрямую.

В Environment добавьте:

| Переменная | Значение |
| --- | --- |
| `LT_PORT` | `10000` |
| `LT_LOAD_ONLY` | `en,ru` |
| `LT_DISABLE_WEB_UI` | `true` |
| `LT_REQ_LIMIT` | `30` |
| `LT_TRANSLATION_CACHE` | `all` |

После первого успешного деплоя скопируйте публичный HTTPS-адрес сервиса, например `https://whatcook-translate.onrender.com`. В Environment сервиса фронтенда добавьте `VITE_LIBRETRANSLATE_URL` с этим адресом и запустите новый деплой фронтенда. Vite встраивает эту переменную в собранное приложение, поэтому одного сохранения переменной без нового деплоя недостаточно.

Проверьте адрес переводчика в браузере запросом к `/languages` — должен вернуться список языков. Успешный рабочий перевод проверяется на странице рецептов поиском русского слова, например «десерт».

Модели требуют оперативной памяти и места на диске. Для Render или другого хостинга выбирайте тариф, на котором LibreTranslate может загрузить модели; при перезапуске без постоянного диска модели могут скачиваться заново. Ограничение запросов снижает риск случайной перегрузки публичного сервиса.

## Как устроен перевод в приложении

- Пары языков: английский ↔ русский.
- Названия и категории переводятся при загрузке и кэшируются в браузере.
- Название, описание, ингредиенты и шаги рецепта переводятся только для отображения.
- Русский запрос переводится на английский перед поиском в каталоге и TheMealDB. Запрос передаётся как написан; исправления опечаток нет.
- Для частых продуктов и категорий есть локальный словарь, поэтому холодильник и подсказки остаются русскими даже без соединения с LibreTranslate.
- Если сервис не настроен или недоступен, приложение использует кэш и локальный словарь, а для неизвестного текста показывает оригинал.
