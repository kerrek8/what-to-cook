# Modern Shadcn Aesthetic, UI Contrast Fixes, System Bars & Notification Worker Audit

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the visual appearance of WhatCook into a clean, modern **Shadcn Slate/Zinc aesthetic** (eliminating all beige tones `#FAF8F5`/`#F0ECE4` in favor of crisp white cards, cool `#F8FAFC` canvas, and sharp `#E2E8F0` borders), fix invisible text on plain/secondary buttons (such as the Registration button), update OS system bars (`<meta name="theme-color">`) from old `#2e7d32` to the new palette, and audit the backend notification worker & mobile Web Push behavior.

**Architecture:**
1. **Design System & Palette (Shadcn Slate/Zinc)**:
   - Replace warm/beige tokens (`#FAF8F5`, `#F0ECE4`, `#E8A87C`) with the modern Shadcn Slate design tokens:
     - Canvas: Cool Slate `#F8FAFC` (slate-50).
     - Cards / Surfaces: Pure White `#FFFFFF` with crisp border `1px solid #E2E8F0` (slate-200) and sharp, clean elevation (`0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1)`).
     - Primary Brand / Actions: Deep Obsidian Slate `#0F172A` (slate-900) or Modern Deep Forest `#14532D` (emerald-900).
     - Text Hierarchy: Primary `#0F172A` (slate-900), Muted `#64748B` (slate-500), Subtle `#94A3B8` (slate-400).
     - Accent / Highlights: Amber `#F59E0B` and Rose `#E11D48`.
2. **Button Text Visibility Fix**:
   - In `main.css`, ensure `.van-button--plain` retains high-contrast text (`color: var(--van-primary-color) !important; background-color: #FFFFFF !important;`) rather than having `.van-button--primary` force a dark background onto plain buttons.
3. **OS Mobile System Bars & PWA Manifest**:
   - Update `frontend/index.html` (`<meta name="theme-color" content="#F8FAFC">`) and `frontend/vite.config.ts` (`theme_color: '#F8FAFC'`, `background_color: '#FFFFFF'`).
4. **Notification Worker & Web Push Audit**:
   - Document how `ExpirationWorker` and Web Push function:
     - Ticker starts every 24h, sends notifications via VAPID (`SherClockHolmes/webpush-go`) to subscriptions stored in PostgreSQL.
     - Why notifications might not arrive:
       a) iOS requires PWA installed to Home Screen (Safari tab push is blocked by Apple).
       b) Android requires notification permissions granted and battery saver not killing background push.
       c) Local IndexedDB products must be synced to PostgreSQL backend (`syncWithServer`).
       d) VAPID keys must be valid in `.env`.
       e) Worker timer runs every 24h without an immediate tick on server startup. We provide an immediate tick on worker start and an on-demand test push trigger.

**Tech Stack:** Vue 3, TypeScript, Vant UI 4 + Tailwind CSS (Shadcn Slate theme), Vitest, Go 1.22+, Gin, PostgreSQL.

## Global Constraints

- **Zero Beige**: No `#FAF8F5`, `#F0ECE4`, or `#E8A87C` in app theme.
- **Zero Legacy Green**: No `#2e7d32` anywhere (including `index.html`, `vite.config.ts`, `favicon.svg`).
- **Button Contrast**: All buttons (solid, plain, secondary, ghost) must satisfy WCAG AA contrast (>= 4.5:1).
- **SemVer**: Bump version to `v0.8.3` in `frontend/package.json` and `ProfileView.vue`.

## Review Focus

1. **Registration & Plain Buttons Contrast**: Text on `<van-button plain>` must be distinctly visible with crisp contrast on white backgrounds.
2. **OS System Bars**: Status bar (top) and navigation bar (bottom) on mobile Android/iOS must render in `#F8FAFC` / `#FFFFFF`, not `#2e7d32`.
3. **PWA Standalone & Theme Color**: `manifest.webmanifest` generated by Vite PWA must reflect new theme color.
4. **Expiration Worker Startup Tick**: Worker must check expiring products immediately upon server startup rather than waiting 24 hours for the first tick.
5. **Mobile Push Requirements**: Clear documentation and in-app diagnostics for Web Push subscription state in Profile settings.

```go
func (w *ExpirationWorker) Start() {
	go func() {
		defer close(w.doneChan)
		// Run immediate check on startup
		ctx, cancel := context.WithTimeout(context.Background(), 2*time.Minute)
		_, _ = w.service.CheckAndNotifyExpiring(ctx, time.Now())
		cancel()

		ticker := time.NewTicker(w.interval)
		defer ticker.Stop()

		for {
			select {
			case <-ticker.C:
				ctx, cancel := context.WithTimeout(context.Background(), 2*time.Minute)
				_, _ = w.service.CheckAndNotifyExpiring(ctx, time.Now())
				cancel()
			case <-w.stopChan:
				return
			}
		}
	}()
}
```
